# SQLCaseStudyIPL

This project analyzes IPL auction data using SQL queries and an interactive Power BI dashboard and demonstrates end‑to‑end skills in data extraction, transformation, and visualization for business intelligence.

Tech Stack:

SQL (PostgreSQL/MySQL) 

Joins, CTEs, Window Functions, Subqueries, CASE statements

Power BI – Interactive dashboards, KPIs, slicers, and visual storytelling.
